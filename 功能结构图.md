## 核心功能流程

### 1. 预约挂号流程
```
用户登录 → 选择科室 → 选择医生 → 选择排班时段 → 填写预约信息 → 确认预约 → 生成预约记录
```

### 2. 用户认证流程
```
用户注册/登录 → 身份验证 → 生成JWT令牌 → 访问受保护资源 → 令牌验证 → 授权访问
```

### 3. AI问诊流程
```
用户进入问诊界面 → 描述症状 → 系统AI分析 → 生成诊断建议 → 保存问诊记录
```

### 4. 流量控制机制
```
API请求 → Sentinel拦截 → 检查流控规则 → 允许/拒绝请求 → 记录监控数据
```

## 数据实体关系

```
┌─────────┐      ┌───────────┐      ┌───────────┐
│  User   │      │  Patient  │      │ Appointment │
└─────────┘      └───────────┘      └───────────┘
    │                  │                  │
    │ 1:1              │ 1:N              │
    ▼                  ▼                  ▼
┌───────────┐      ┌───────────┐      ┌───────────┐
│ Doctor   │◄──────┤  Schedule │◄──────┤ Department │
└───────────┘      └───────────┘      └───────────┘
```

* User与Patient是一对一关系
* Patient与Appointment是一对多关系
* Department与Doctor是一对多关系
* Doctor与Schedule是一对多关系
* Schedule与Appointment是一对多关系
